# v2rayN 应用分流助手

适用于 v2rayN 7.x（sing-box 内核 / TUN 模式）的独立应用分流配置工具。

- **全部直连**：名单内的应用访问国内外网站都直连
- **国内外分流**：名单内的应用国内网站直连、国外网站走代理
- 未加入名单的应用默认全部走代理，局域网保留直连

## 功能

- 任务管理器风格的进程列表：区分「应用 / 后台进程 / Windows 进程」，带图标，可展开查看子进程
- 准星拖拽：按住准星拖到任意窗口上松开，自动定位并勾选该窗口所属进程
- 勾选即加入名单，进程列表右下角「保存」直接写入 v2rayN
- 主窗口中的修改自动保存，保存结果以自动消失的通知提示
- 每次保存前自动备份，并用 sing-box 校验规则

## 构建

只需要 Windows 自带的 .NET Framework 4.x：

```powershell
.\build.ps1          # 输出 bin\应用分流助手.exe
.\build.ps1 -Test    # 同时编译测试程序
```
