# v2rayN 应用分流助手

适用于 v2rayN 7.x（sing-box 内核 / TUN 模式）的独立应用分流配置工具。

- **全部直连**：名单内的应用访问国内外网站都直连
- **国内外分流**：名单内的应用国内网站直连、国外网站走代理
- 未加入名单的应用默认全部走代理，局域网保留直连

## 功能

- 「按应用」页：把 .exe 或快捷方式直接拖进名单，或从正在运行的程序中勾选（任务管理器风格，可用准星拖到窗口上定位进程）
- 「按域名 / IP」页：直连、走代理两份名单，对所有应用生效且优先于应用名单；输入框回车添加，可一次粘贴多条，粘贴网址自动提取主域名；双击条目直接修改（写法见标题旁的问号）
- 鼠标悬停条目即可移到另一侧或删除，也可以把条目拖到另一侧名单；支持右键菜单和 Delete 键
- 左侧「规则集」：点击切换，「+」新建，双击重命名，悬停 / 右键 / Delete 删除（v2rayN 正在使用的不能删，删除前自动备份）
- 第二行显示 v2rayN 位置：启动时自动检测正在运行的 v2rayN，「刷新」重新检测并读取，「选择…」手动指定
- 所有修改自动保存（保存前备份并用 sing-box 校验），重启 v2rayN 后生效
- 顶栏实时显示 v2rayN 的模式：处于「全局」或「直连」模式、或没有使用这个规则集时，会提示如何处理

> 分流只在 v2rayN 的「规则」模式下生效：在 v2rayN 左侧「当前代理」页把规则模式切换为 Rule。

## 构建

只需要 Windows 自带的 .NET Framework 4.x：

```powershell
.\build.ps1          # 输出 bin\应用分流助手.exe
.\build.ps1 -Test    # 同时编译测试程序
```
